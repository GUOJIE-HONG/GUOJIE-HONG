# README.md surface brief

Scope: GitHub profile README (`README.md` + `assets/`). Visitor mode: Persuade.

Audience: recruiters checking whether he can do a backend-leaning full-stack job, and developers deciding whether to install `skills`. Both equal.
Actions: developers copy the `skills` install command; recruiters reach Email or the portfolio.
Proof: `skills` is the only featured project. No invented numbers, levels, or stats.
Constraints: GitHub strips CSS and JS; SVG loads as `<img>`, so type is outlined to paths; `<picture>` serves light and dark variants.

## Direction contract

THESIS: The information is the design. Refuses the badge wall, stats cards, typing banner and every game metaphor.

OWN-WORLD: Swiss International Typographic Style. Six-column grid, flush-left Archivo in extreme scale contrast, Noto Sans TC for Chinese. Black ink on the page's own ground, one International Orange (#ff4f00) field reserved for `skills`. Thick rules, no ornament.

STORY: Visitor learns he is a C# / ASP.NET Core backend engineer who works from evidence, sees `skills` as that method made public, copies the install command or emails him.

FIRST VIEWPORT: "Jacob / Hong" at poster scale across columns 1–5; an orange field bleeds from column 4 to the right and bottom edges, "Hong" overprinting it; `skills` and "Evidence, never guesswork." sit inside. Bottom left: 後端工程師 with BACKEND ENGINEER beneath. The field wipes in once along the grid; then everything is still.

FORM: Swiss International Typographic poster, position 6 on the ordered list (round 2), seed key 91269be4.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Raises: bilingual headings (Chinese headline, English beneath) from the command-center challenger; `skills` stages in their fixed order from the darkroom challenger; honest emptiness, one project only, from the video-store challenger.
